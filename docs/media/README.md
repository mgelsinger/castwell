# Castwell demo media

These assets show the actual Castwell browser interface running against an isolated local library:

- [`castwell-tour.gif`](castwell-tour.gif): a looping preview for the project README.
- [`castwell-tour.mp4`](castwell-tour.mp4): the same tour as a higher-resolution, silent video.
- [`../images/ad-review.png`](../images/ad-review.png): the real review panel, waveform, selected cut, and export controls.

The four podcast entries are synthetic demonstration fixtures. The audio is a generated tone with a varying waveform. The sample transcript was authored and imported, so this tour does not demonstrate speech transcription quality. No podcast audio, external artwork, speech model, or AI service is used.

The tour runs local heuristic detection on the imported transcript, reviews a suggested cut from 6 to 14 seconds, exports actual cleaned audio with FFmpeg, switches playback from the 24-second original to the 16-second cleaned copy, and displays the matching cleaned transcript. The original recording remains available.

The screenshot, GIF and video were refreshed on October 8, 2026 to include the current score labels, review status and bulk-selection controls. The MP4 is 1280 by 848 at 24 fps, about 26 seconds long; the GIF is 960 by 636 at 8 fps. This refresh checks the interface and export workflow, not model accuracy.

## Reproduce

From a development environment with the project's development dependencies, FFmpeg, and a Playwright Chromium browser available:

```sh
python scripts/record_demo.py
```

To use an existing Chromium executable:

```sh
python scripts/record_demo.py --chromium /path/to/chromium
```

The capture helper creates temporary library data and generated audio outside the checkout and removes them when finished. It writes the three media assets under `docs/`. Use `--output /path/to/output` to write elsewhere. Video captions are presentation overlays; the application interface is captured directly from the running app.

The older `docs/images/gallery.png` is a separate existing project asset and is not regenerated by this helper.
